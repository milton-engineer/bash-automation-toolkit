# Bash Automation Toolkit

Collection of lightweight Linux automation scripts focused on system maintenance, diagnostics and infrastructure workflows.

## Overview

Bash Automation Toolkit is a set of utility scripts designed to automate repetitive Linux administration tasks and assist in troubleshooting environments.

The project simulates real-world automation practices used in Linux infrastructure and backend support operations.

## Features

- Disk usage inspection
- Log cleanup automation
- Service status checking
- Backup automation
- Basic system diagnostics

## Technologies

- Bash
- Linux

## Goals

- Practice infrastructure automation
- Improve Linux maintenance workflows
- Build lightweight administration utilities
- Simulate real-world DevOps tasks
